⚙ Configurar GitHub

Os dados ficam em dados.json no seu repositório. Cada salvamento cria um commit automático.

  1. Crie o repositório (se ainda não existe)
    github.com/new → nome: onze-inventario-ti → Privado ✓ → Criar
  2. Gere um Personal Access Token
    github.com/settings/tokens/new → Nome: inventario-ti → Marque repo → Gerar → copiar
  3. Preencha abaixo e clique em Salvar Config
🔒 O token fica armazenado apenas neste navegador (localStorage). Nunca é enviado a nenhum servidor além do GitHub.
